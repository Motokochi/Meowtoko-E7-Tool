EPIC SEVEN FULL TRAFFIC CAPTURE

1. Close browsers and every unrelated app you can.
2. Double-click Capture-Epic-Seven-Traffic.cmd.
3. Accept the Administrator prompt and the privacy warning.
4. Follow the steps shown in the capture window.
5. Send EpicSeven-Full-Traffic.pcapng from the newly created E7-Capture folder.

The capture contains complete packets from every physical and virtual network
adapter. Treat it like sensitive account data. Do not post it publicly.

If the capture window is closed while recording, open Command Prompt as
Administrator and run:

    pktmon stop

Requirements: Windows 10 version 2004 or newer. No software installation is
needed; this uses Windows Packet Monitor.
