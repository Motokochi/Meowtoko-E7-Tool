# Meowtoko E7 Tool 0.1.34

Make game inventory capture steps reliable

## Highlights

- Show the complete capture sequence in the Importer: close Epic Seven, start
  capture, reopen the game, wait for the Lobby, and then finish capture.
- Keep packet capture active for one additional second after clicking
  `Done Capturing` so late in-flight packets are included.
- Correct retry messages so they consistently instruct users to start capture
  before reopening Epic Seven.

## Install

Download `Meowtoko-E7-Tool-0.1.34-Setup.exe` from this release. Close Meowtoko E7 Tool,
run the installer, and accept the expected unsigned-publisher warning only
when your own Windows or organization policy allows it.
