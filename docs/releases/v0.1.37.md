# Meowtoko E7 Tool 0.1.37

Exclude flat stats from the matching-roll rescue rule

## Highlights

- Quadroll and pentaroll protection now applies only to non-flat substats. Low-GS
  pieces cannot survive solely because enhancement rolls repeatedly hit flat
  Attack, Defense, or Health.

## Install

Download `Meowtoko-E7-Tool-0.1.37-Setup.exe` from this release. Close Meowtoko E7 Tool,
run the installer, and accept the expected unsigned-publisher warning only
when your own Windows or organization policy allows it.

## Integrity

Verify downloaded files against `SHA256SUMS.txt` attached to this release.
