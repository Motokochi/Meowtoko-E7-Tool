# Meowtoko E7 Tool 0.1.33

Improve LDPlayer game capture compatibility

## Highlights

- Open the validated Npcap network interfaces reported by Scapy instead of
  resolving their raw Windows device names again during capture startup.
- Include sanitized active-adapter and TCP source-port counts when a capture
  sees network traffic but no supported game response, making another miss
  actionable without recording or exposing packet contents.
- Preserve the existing private AWS decoding boundary and Automatic Enhancer
  behavior.

## Install

Download `Meowtoko-E7-Tool-0.1.33-Setup.exe` from this release. Close Meowtoko E7 Tool,
run the installer, and accept the expected unsigned-publisher warning only
when your own Windows or organization policy allows it.

## Integrity

Verify downloaded files against `SHA256SUMS.txt` attached to this release.
