# Meowtoko E7 Tool 0.1.32

Remove stale E7 Hub entries after upgrading

## Highlights

- Remove obsolete E7 Hub Start-menu and desktop shortcuts during installation
  and updates so Windows no longer presents the retired name beside Meowtoko E7 Tool.
- Preserve the existing application data, inventory, profiles, results, and
  in-place update compatibility while cleaning up the old display entry.

## Install

Download `Meowtoko-E7-Tool-0.1.32-Setup.exe` from this release. Close Meowtoko E7 Tool,
run the installer, and accept the expected unsigned-publisher warning only
when your own Windows or organization policy allows it.

## Integrity

Verify downloaded files against `SHA256SUMS.txt` attached to this release.
