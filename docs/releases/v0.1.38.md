# Meowtoko E7 Tool 0.1.38

Replace inferred gear archetypes with reviewed Hero Journal builds

## Highlights

- Rebuild gear archetypes from reviewed Hero Journal screenshots instead of population-wide inferred stat signatures.
- Consolidate overlapping builds into 28 functional archetypes with hero- and equipment-set-specific recommendations.
- Respect alternative bulk-stat slots and manual build corrections so incidental or obsolete stats no longer make gear look desirable.

## Install

Download `Meowtoko-E7-Tool-0.1.38-Setup.exe` from this release. Close Meowtoko E7 Tool,
run the installer, and accept the expected unsigned-publisher warning only
when your own Windows or organization policy allows it.

## Integrity

Verify downloaded files against `SHA256SUMS.txt` attached to this release.
