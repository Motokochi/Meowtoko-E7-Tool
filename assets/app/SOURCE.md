## Origin

The emblem was generated specifically for Meowtoko E7 Tool on 2026-07-25 with OpenAI's
built-in image-generation tool. It was created without an input image or
third-party logo. The generated chroma-key background was removed locally and
the result was deterministically resized to a 1024 x 1024 RGBA PNG. The ICO
contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel variants derived from
that PNG.

The previous project icon was replaced before the repository became public
because its original contributor/source record was unavailable.

## Generation prompt

> Create an original desktop-app emblem formed from a polished, faceted violet
> crystal shaped like a subtle number 7 and a thin cyan orbital ring. Use no
> copyrighted characters, game logos, weapons, recognizable third-party
> symbols, text, or watermark. Keep a strong centered silhouette that remains
> readable at 16 pixels.
